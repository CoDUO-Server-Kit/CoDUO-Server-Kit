=====================================================================
 CoDUO Server Kit - PAQUETE LISTO PARA JUGAR
 Call of Duty: United Offensive 1.51  -  mod T-FBB + mapas + bots + motor HD
=====================================================================

Creado por Leandro Guzman en colaboracion con GERARD!, Gaston, Miguel Soldier,
Guille, Jubilado, Pyro y Sr-Oscuro. Proyecto: https://github.com/CoDUO-Server-Kit/CoDUO-Server-Kit

QUE NECESITAS
-------------
- Call of Duty + United Offensive ORIGINAL, actualizado a la version 1.51.
  (Este paquete NO trae el juego.)
- Windows 7 SP1 o superior con .NET Framework 4.5 o mas nuevo (4.8 recomendado).
- Para el motor HD: Windows de 64 bits.

COMO SE INSTALA (1 minuto)
--------------------------
1. Abri la carpeta donde esta instalado el juego (la que tiene CoDUOMP.exe),
   por ejemplo:  C:\Juegos\Call of Duty UO
2. Copia ADENTRO de esa carpeta el contenido de este paquete:
      CoDUOKit\   (el mod, los mapas y los bots)
      Launcher\   (el launcher)
      uo\         (si te pregunta por uomappack00.pk3, acepta reemplazar)
3. Abri  Launcher\CoDUOKitLauncher.exe
   - La primera vez te pide tu nombre de jugador.
   - JUGAR: abre el juego con el mod.
   - PRACTICA: elegis modo, mapa, cantidad de bots, dificultad y punteria,
     y jugas contra bots en tu PC, sin internet.
   - Teclas, Pantalla, Resolucion, Monitor y Mostrar FPS se configuran desde el launcher.
   - "Motor mejorado (graficos)": activa el motor HD. Al destildarlo vuelve al original.

SOBRE EL MOTOR HD
-----------------
- Es "Open CoD:UO 1.51", de su autor "brague". El launcher guarda tus archivos
  originales y los restaura cuando destildas la casilla.
- No esta firmado digitalmente: Windows o el antivirus pueden avisar la primera vez.
- Si tenes Windows de 32 bits la casilla no aparece (el motor HD es de 64 bits).

ARMAS MODERNAS, SOLDADOS Y RACHAS (eBus Hardline)
-------------------------------------------------
El paquete trae z_zzz_kit_hardline.pk3, armado con contenido del mod "eBus Hardline"
(de eBus / ebusiangamers para el clan RRMS Snipers Clan).
- Menu de armas: pestana HARDLINE con 27 armas modernas en 4 categorias (Asalto,
  Compactas, Tirador, Pesadas). Al costado se ven el dano, el cargador, la cadencia
  y la movilidad de cada una.
- Soldados modernos: 2 por bando (Delta Force, US Army, SAS, Spetsnaz, milicia,
  bandidos), uno al azar cada vez que apareces.
- Racha HARRIER: hace 7 bajas seguidas sin morir. Despues, quieto, en el piso y a
  cielo abierto, MANTENE APRETADA la tecla USAR 1,5 segundos: pasas a una camara
  aerea con el canon de 40 mm durante 30 segundos. Mientras estas en el aire no
  recibis dano.
- Racha LOKI (camara satelital con los canones del AC-130): viene APAGADA.
- En algunos mapas (los que pasan el limite de modelos del juego) todo esto se apaga
  solo y se juega con el mod tal cual.

Para apagar cosas en un servidor (en server.cfg):
    set scr_allow_hardline "0"          // sin armas de Hardline
    set scr_hl_soldados "0"             // soldados originales de la Segunda Guerra
    set scr_racha_harrier "0"           // sin Harrier (por defecto 7 bajas)
    set scr_racha_harrier_tiempo "30"   // segundos que dura el Harrier
    set scr_racha_loki "5"              // activar el Loki con 5 bajas (por defecto 0 = apagado)
    set scr_racha_proteger "0"          // que el jugador SI reciba dano en el aire
Si el servidor es Linux, despues de subir el pk3 y reiniciar, lee la consola del
servidor antes de jugar (ver docs/GUIA.md, seccion 20).

COMPROBAR QUE EL PAQUETE ES EL ORIGINAL
---------------------------------------
Los programas no estan firmados digitalmente. Bajalo solo de la pagina de Releases del
proyecto y compara las huellas SHA-256 con las que figuran en las notas del Release:
    certutil -hashfile Launcher\CoDUOKitLauncher.exe SHA256
Si no coinciden, no lo uses.

PROBLEMAS COMUNES
-----------------
- Textos raros tipo EXE_CONNECTINGTO: abri el juego desde el launcher (lo corrige solo).
- Cartel de "Modo Seguro": lo evita el launcher; si aparece, usa el boton Reparar.
- Pantalla muy blanca despues de cerrar el juego: el launcher la restaura al cerrar.
- El mouse no responde en la practica: hace clic una vez en la ventana del juego.

USARLO CON UN SERVIDOR
----------------------
Opcion 1 - Servidor con este mismo paquete (sin actualizaciones automaticas):
  - Segui Servidor\LEEME_SERVIDOR.txt (subir CoDUOKit al servidor Linux, server.cfg, etc.).
  - Cada jugador abre Launcher\config.json con el Bloc de notas y pone la IP:
        "server": "IP_DEL_SERVIDOR:28960",
    Al abrir el launcher aparece el boton ENTRAR AL SERVIDOR.
Opcion 2 - Con actualizaciones automaticas (el launcher baja solo cada cambio):
  - Hace falta un repositorio privado en GitHub y dos tokens. Completas en config.json
    "owner", "repo" y "token", y publicas con la herramienta del proyecto.
  - Recomendado: firma las actualizaciones (herramientas\Generar_Claves.ps1 y el campo
    "publicKey" de config.json), asi nadie puede repartir archivos a tus jugadores
    aunque consiga tu token de GitHub. Ver docs/GUIA.md, paso 4.
  - Guia paso a paso: docs/GUIA.md en GitHub (pasos 3 a 5).
