# Seguridad / Security

## Reportar una vulnerabilidad

Si encontraste un problema de seguridad en el kit (por ejemplo, una forma de que el launcher baje o ejecute algo que no publicó el administrador, o de filtrar tokens o claves), **no abras un *issue* público**.

Reportalo en privado desde la pestaña **Security → Report a vulnerability** de este repositorio. Contanos:

- qué parte del kit es (launcher, parche, herramientas, top del mes, bots),
- cómo reproducirlo, paso a paso,
- qué podría hacer alguien que lo aproveche.

Respondemos apenas podamos (es un proyecto hecho en el tiempo libre). Cuando esté corregido, publicamos una versión nueva y te damos el crédito, si querés.

## Qué está dentro del alcance

- El código de este repositorio: `launcher/`, `parche/`, `herramientas/`, `estadisticas/`, `practica_src/`.
- El paquete listo para jugar de *Releases*, en lo que respecta al kit.

**Fuera del alcance:** el juego (Activision), el motor del juego, el motor HD y los mods o mapas de terceros. Reportá esos problemas a sus autores (ver [CREDITS.md](CREDITS.md)).

## Versiones con soporte

Solo la última versión publicada en *Releases*.

---

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via **Security → Report a vulnerability** in this repository, with the affected component, steps to reproduce and impact. Only the latest release is supported. The game, game engine, HD engine and third-party mods/maps are out of scope.
